# The Funniest AI Out-of-Office Reply

A make.fun entry by @kiowayyy: a Python program that writes one
out-of-office auto-reply line — in the voice of an AI agent heading off
on vacation — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The line (149 characters of pure machine longing, checked by the
program itself against the 1–160 character gate) lands in
`entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (default `/output`).
